# 修复复杂帖子退出后持续卡顿

## Goal

根据 2026-07-17 真机性能追踪，修复连续浏览复杂帖子、查看多张原图后，解码图片和复杂详情快照持续驻留，导致退出帖子后首页、设置等无关页面仍掉帧和不跟手的问题，同时完整保留现有帖子渲染、首页详细展示、首帖即时承接和评论渐进加载体验。

## Confirmed Facts

- 新日志保留了会话约 556 秒到 1023 秒的 2026 条记录，其中有 553 条慢帧、79 个帧窗口和 36 次路由事件。
- 复杂帖子 `2584862` 浏览期间多次进入图片查看器；Flutter 解码图片缓存从约 34MB/194 项增长到约 69MB/253 项。
- 退出该帖子和其来源页面后，图片缓存仍保持约 69MB/253 项；随后首页出现 115ms、118ms、129ms 冻结帧，设置页仍出现 104ms 帧，证明高负载资源跨路由残留。
- 这些退出后的冻结帧包含 55–59ms raster 和 36–56ms pipeline wait；网络附件中的 MessageBus 请求是后台长轮询，没有证据显示网络等待阻塞 UI isolate。
- 图片查看器当前使用未限制尺寸的原图 `ImageProvider`，关闭后没有主动释放这些只服务于全屏查看的解码缓存；帖子正文使用带尺寸约束的独立 provider key，因此可以只清理查看器原图而不破坏正文缩略图。
- 话题详情运行期缓存只按帖子数量限制。少量但包含超长 HTML、代码、图片和链接的复杂帖子仍可被缓存，最多保留 8 个移动端详情快照，复杂内容可能在退出后继续占用 Dart heap。
- 首页详细展示通过 preview seed 和路由携带的首帖 HTML 实现；性能修复不能取消、延迟或弱化该路径。

## Requirements

- 图片查看器必须复用同一 URL 的全尺寸 provider，避免查看器自身 rebuild 重复创建 provider identity。
- 图片查看器关闭并完成 widget 销毁后，只释放本次查看器实际创建的全尺寸原图内存缓存；保留磁盘缓存、正文缩略图/限制尺寸图片缓存和图片查看器全部交互行为。
- 全尺寸图片释放必须异步执行，不能在路由 pop 动画或 widget finalization 热路径同步做重工作；单个 provider 释放失败不能影响其他 provider 或页面退出。
- 话题详情运行期缓存除帖子数外，还必须按已加载正文内容规模限制单条快照和移动端总驻留规模；超大完整详情不得替换为长期驻留缓存。
- preview seed 必须继续允许首帖即时承接，并在写入时优先保留当前 seed、按 LRU 淘汰较旧缓存；完整详情若超限，可放弃运行期复用但不能影响当前详情页展示和渐进加载。
- 不修改首页帖子卡片样式、尺寸、颜色、排版、动画或内容。
- 不修改“首页详细展示”的开关逻辑、请求逻辑、首帖即时承接、评论渐进加载、搜索/书签/历史导航、目标楼层、嵌套回复、图片手势或视频行为。
- 两个独立根因分别提交，不能混入用户已有未跟踪文件、历史 Trellis 目录或密钥。

## Acceptance Criteria

- [ ] 单图和画廊查看器对相同原图 URL 复用稳定 provider；关闭查看器后，本次创建的原图 provider 被逐个异步 evict，异常被隔离。
- [ ] 清理不包含 thumbnail provider，不删除磁盘缓存，不改变正文受限尺寸 provider key；再次打开图片仍可从磁盘重新解码并正常缩放、滑动、Hero 返回。
- [ ] 普通详情快照在帖子数或正文规模超过上限时不进入长期缓存；多个中等快照超过总预算时按 LRU 淘汰。
- [ ] preview seed 即使正文较大也能立即写入并用于目标楼层/普通详情首帖承接，同时挤出较旧缓存；后续完整超大详情不会继续长期驻留。
- [ ] 首页详细展示、详情预览承接、目标楼层、渐进加载、图片查看器相关定向测试通过。
- [ ] 全量 `flutter test --no-pub`、`flutter analyze --no-pub`、`git diff --check` 通过，无调试残留。
- [ ] 改动按“图片查看器原图释放”“复杂详情缓存限额”“规范/任务记录”拆分本地提交，复核后统一推送到 `origin/codex/rollback-to-v0.3.1`。

## Out of Scope

- 禁用图片、动图、视频、代码块或复杂 HTML。
- 清空整个全局图片缓存，或在退出帖子时让首页头像、卡片缩略图全部重新解码。
- 改变详情网络请求协议、评论加载顺序、首页摘要样式或交互逻辑。
- 把 MessageBus 长轮询耗时当作 UI 卡顿根因。
