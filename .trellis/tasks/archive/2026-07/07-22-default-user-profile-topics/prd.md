# 用户主页默认显示话题

## Goal

从任何头像入口进入用户主页时，默认展示“话题”标签而不是“总结”。

## Requirements

- `TabController` 初始索引指向现有“话题”标签（filter `4`）。
- 页面初始化时立即加载该用户的话题动作列表，不能等待用户手动切换标签。
- 总结、动态、回复、点赞和回应标签及切换后的懒加载保持可用。
- 用户资料头部和总结统计请求保持兼容。

## Acceptance Criteria

- [x] 新建用户主页首帧选中“话题”，对应 TabBarView 为话题列表。
- [x] 首次进入会加载 filter `4`，且不会重复加载。
- [x] 其他标签切换与分页行为不变，定向测试通过；全量检查在父任务集成门禁执行。

## Out of Scope

- 调整标签顺序、名称或移除总结。

## Open Questions

- 无。
