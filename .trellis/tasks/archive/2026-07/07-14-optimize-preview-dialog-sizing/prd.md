# 优化预览弹窗自适应高度与边框

## Goal

将85%安全视口高度改为上限，设置合理最低高度，按实际内容平滑自适应，并移除突兀顶部色带、改为统一轻量边框。

## Requirements

- 将当前 `viewportHeightFactor = 0.85` 保留为最大高度上限。
- 最低高度采用安全视口的合理比例，并设置绝对下限/上限以适配小屏和大屏，避免两行正文时过高或整体过矮。
- 使用内容真实布局决定最终高度；正文超过可用空间时继续在弹窗内部滚动。
- 异步加载前展示稳定的最低高度骨架，正文到达后以短时 ease-out 尺寸动画过渡到实际高度。
- 不使用 `IntrinsicHeight`、动态模糊或其他会显著增加复杂 HTML 布局成本的方案。
- 删除顶部 4px 渐变色带，用四边一致的细描边配合现有圆角和阴影。
- 在作者/分类/标签元信息与正文之间增加一条低透明度细分隔线；无标签时也保持相同的信息层级分隔。
- 书签等带自定义操作区的预览仍不能溢出最大高度。

## Acceptance Criteria

- [ ] 390×844 测试视口下，短正文高度大于等于最低高度且小于 85% 上限。
- [ ] 长正文高度不超过 85% 上限，内部仍可滚动且无布局异常。
- [ ] 加载完成后的高度变化由 `AnimatedSize` 或等价轻量动画承接。
- [ ] 弹窗不存在仅顶部可见的色带，四周描边一致。
- [ ] 标签区域下方使用与详情页一致的轻量分隔线，清楚区分元信息和正文。
- [ ] “查看详情”、统计栏、标签单行及 preview seed 交接行为保持不变。

## Out of Scope

- 不用字符数直接预测复杂 HTML 的像素高度。
- 不改正文 HTML 渲染规则和图片/代码能力。
