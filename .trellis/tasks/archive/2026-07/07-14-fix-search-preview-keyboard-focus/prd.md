# 修复搜索预览关闭后输入法弹出

## Goal

搜索结果触发话题预览前释放搜索框焦点，关闭预览后不自动恢复焦点和弹出输入法；独立提交。

## Requirements

- 所有通过 `SearchPreviewDialog` 打开的搜索结果预览，在推入弹窗路由前必须清除当前输入焦点及搜索 scope 的历史焦点。
- 关闭预览后不能把焦点恢复给原搜索输入框，也不能自动弹出软键盘。
- 用户主动点击搜索框时仍可正常获取焦点并输入；不改变普通帖子点击进入详情的行为。
- 修复应覆盖主搜索页以及书签/历史等复用 `SearchPreviewDialog` 的内容搜索入口。

## Acceptance Criteria

- [ ] 搜索框处于焦点状态时打开预览，焦点立即释放。
- [ ] 关闭预览并返回搜索结果列表后，搜索框保持失焦，输入法不自动弹出。
- [ ] 搜索预览布局、触发方式和查看详情行为保持不变。
- [ ] 添加 widget 回归测试覆盖预览打开及关闭后的焦点状态。

## Out of Scope

- 不修改全局 dialog route 的焦点策略，避免影响登录、编辑器等确实需要恢复输入焦点的弹窗。
- 不禁止用户返回后主动点击搜索框。
