# 突出帖子预览回复数

## Goal

让用户在帖子预览弹窗底部快速识别回复数，尤其一眼判断是否为 0，减少无意义的“查看详情”点击。

## Requirements

- 保持左侧回复/浏览、中间查看详情、右侧点赞/时间的三栏结构。
- 只强化回复统计：图标和数字字号明显大于其他统计，并使用更高强调色/字重。
- 回复数计算仍为 `max(postsCount - 1, 0)`，不改变数据来源。
- 窄屏和大字体下仍通过现有缩放/约束避免溢出或挤压中央按钮。

## Acceptance Criteria

- [x] 回复图标和数字的配置大于其他 compact stat，0 回复清晰可见。
- [x] 浏览、点赞、时间样式保持现状，“查看详情”位置和行为不变。
- [x] 预览弹窗几何和定向 widget 测试通过。

## Out of Scope

- 改动预览主体、按钮文案或新增回复筛选。
