# 优化话题预览触发与窗口体验

## Goal

让用户可在“长按卡片”和“点击卡片右侧信息区”两种预览触发方式之间二选一，并统一优化首页、书签、浏览历史和搜索页的话题预览体验：弹窗立即、平滑、固定高度出现，展示更多主帖内容，且进入详情时直接复用已加载主帖。

## Confirmed Facts

- 首页、书签和浏览历史通过共用的 `buildTopicItem` / `TopicCard` 渲染；搜索页复用 `TopicCard` 外观，但仍有独立的预览弹窗入口。
- 当前设置是可关闭的 `longPressPreview` 布尔值，默认开启。
- 当前话题预览弹窗最大高度为屏幕的 70%，加载前按内容收缩，加载后增高，因而产生高度抖动。
- 当前弹窗正文已使用完整的 `DiscourseHtmlContent` HTML 渲染能力，支持代码、图片等复杂内容。
- 详情页与 `TopicDetailCacheService` 已支持只含首帖的 preview seed：首帖可立即展示，完整详情/评论随后后台刷新。

## Requirements

- 将预览触发偏好改为持久化的二选一模式：
  - `longPress`：长按卡片弹出预览；卡片普通点击进入详情。
  - `rightSideTap`：仅点击卡片右侧元信息列覆盖的全高矩形热区弹出预览；点击其余区域进入详情。
- 旧偏好迁移：旧值 `true` 映射为 `longPress`；旧值 `false` 映射为 `rightSideTap`；新安装默认 `longPress`。
- 右侧预览热区不得改变卡片静态外观，不得扩大到标题、头像、分类标签或正文摘要区域。
- 设置页以单选方式展示当前触发模式及两个选项，并提供简体中文、繁体中文和英文文案。
- 首页、书签、浏览历史、搜索，以及其他复用统一话题卡片构建器的列表，使用同一触发偏好和热区行为。
- 预览弹窗固定为安全可用视口约 85% 的高度（对应把原 70% 高度留下的上下边距各缩小一半），加载前后高度不得变化；宽度继续适配手机与大屏，且不完全覆盖屏幕。
- 弹窗打开动画应快速、平滑且无回弹突兀感；避免为该弹窗执行高成本的动画背景模糊。
- 缩小顶部内容边距、标题字号和标题后间距。
- 分类及全部标签只能占一行；使用更小徽章，空间不足时省略后续标签，不换行、不横向滚动。
- 主帖正文占据主要可滚动区域，沿用完整 HTML 渲染能力并采用适合预览的紧凑排版，代码、图片、引用、表格和链接不得退化成纯文本。
- 删除参与者文字和头像行。
- 删除正文下方原有的统计区；将回复、浏览、点赞、最后回复时间放入最底部操作栏，分列于居中的“查看详情”按钮左右。
- 删除底部“关闭”和“分享”按钮；保留点击遮罩关闭能力；缩短底栏高度。
- 点击“查看详情”前，将预览请求得到的首帖详情写入现有 preview-seed 缓存；详情页立即渲染主帖，只在后台请求尚未加载的完整详情/评论。
- 加载失败时保留 excerpt 降级展示；失败不应改变弹窗固定高度。

## Acceptance Criteria

- [x] 设置页只能选择“长按预览”或“点击右侧预览”，重启后选择保持，旧布尔设置按约定迁移。
- [x] `longPress` 模式下长按可预览，点击任意位置仍进入详情。
- [x] `rightSideTap` 模式下点击右侧全高热区可预览；点击标题、头像、标签、摘要和卡片其余区域只进入详情；长按不触发预览。
- [x] 首页、书签、浏览历史和搜索页的卡片触发方式及预览弹窗视觉一致。
- [x] 弹窗初次出现、加载中、加载完成和加载失败状态高度一致，顶部和底部保留约 7.5% 视口间距。
- [x] 标题与顶部间距更紧凑；分类和标签始终单行，超出宽度的后续项不会换行或造成 overflow。
- [x] 正文可滚动并正确呈现复杂 HTML；弹窗内不再显示参与者行。
- [x] 底栏仅有居中的“查看详情”主操作，左右紧凑展示回复、浏览、点赞、最后回复时间，无关闭和分享按钮。
- [x] 从预览点击“查看详情”后，详情页首帖无需等待第二次主帖请求即可显示；完整详情/评论仍会后台加载。
- [x] 相关 Flutter analyze 与定向测试通过，且没有引入卡片点击冲突、布局 overflow 或现有详情跳转回归。

## Out of Scope

- 不改变普通点击卡片进入详情的导航目标、书签回复定位或历史阅读位置规则。
- 不改变评论区的数据请求协议、分页逻辑或详情页整体布局。
- 不新增第三种“关闭预览”模式。
- 不重写全局 HTML 渲染器；仅在预览容器内调整其使用方式和布局约束。

## Open Questions

- 无阻塞问题；实现按上述迁移和布局约束推进。
