# 持续模拟真实浏览并排查 FluxDO 卡顿

## Goal

在 Android Emulator 中以接近普通用户的节奏持续浏览 FluxDO，利用用户已开启的性能诊断和应用日志定位“使用一段时间后出现的浏览、滚动和触摸不跟手”，仅对可重复、日志证实且属于应用自身的性能根因做最小优化。

## Confirmed Facts

- GitHub `v0.6.112` 原始 `arm64-v8a` APK 在手机和其他 ARM 设备正常；其本地文件 SHA-256 仍为 `228CE9BB78458FE72B5C068C08D73CBE09A947F89F1D3A7D3AE87ACE3435FB8C`，必须保持只读。
- `ctf_api30` 是 API 30 / x86_64；模拟器内安装的是同提交、同版本元数据、同签名的 x86_64 direct 兼容包，仅作为测试载体。
- AVD 已启用 AMD host GPU；此前同节奏首页慢帧事件率由 SwiftShader 下的 11.3% 降为 4.8%，说明模拟器渲染开销必须与应用热点分开归因。
- `pref_performance_diagnostics_enabled=true`、`pref_app_logs_enabled=true`；本轮起始性能日志为 715 行。
- 历史任务已修复树形递归物化、单帧物化预算、图片视口解码、内存压力清理、详情中心切换、诊断批量写盘等热点；不得在没有新证据时重复改动。

## Requirements

1. GitHub 原始 APK 只用于校验，不修改、不重签名、不覆盖、不上传；不得把模拟器 ABI 兼容问题描述成官方 APK 缺陷。
2. 真实行为模拟必须采用不规则的中等速度滑动、2–8 秒普通停留、部分 10–20 秒阅读停留、偶尔短距离回看，并包含进帖、逐段阅读、返回首页和继续浏览；禁止机械高速连续甩动。
3. 覆盖至少首页列表、普通文字帖、长回复/树形帖子、含图片或富媒体帖子、重复进出帖子后的首页回访；在站点限流时不绕过风控，不用高频重试污染样本。
4. 不执行点赞、回复、收藏、打赏、关注、修改设置等有副作用操作；不填写或导出账号、Cookie、API Key、代理及 Notion 凭据。
5. 每轮记录起止时间、性能日志行号、PID、路由/页面、截图或 UI 层级、手势节奏及可感知异常；分析只使用本轮起始行之后的新日志。
6. 同时检查 `slow_frame`、`frame_window`、`ui_isolate_stall`、组件 build 归因、图片事件/缓存、路由、滚动、后台请求和系统渲染器，区分模拟器 raster 开销、服务端 429/网络等待与应用 UI 热点。
7. 在日志没有形成可重复的应用热点前不得修改源码。若形成热点，改动只能改善浏览性能，不得改变 UI 几何、颜色、样式、文案、导航语义、数据内容或其他功能。
8. 任何源码改动必须先复现、补定向回归测试、通过适用的 Trellis before-dev/check 流程，并使用同一场景复跑前后对比；无改善或产生行为差异时回滚该改动。

## Acceptance Criteria

- [ ] 完成不少于 30 分钟的分段真实节奏操作，至少 6 轮，且页面和帖子类型覆盖 Requirements 3 的场景。
- [ ] 每轮均有可核对的行号/时间/页面/PID/视觉状态记录，最终日志中不存在无法归属到场景的关键 frozen/severe 突峰。
- [ ] 对每个可感知卡顿候选给出可重复性、主导阶段、组件/资源/请求证据，并明确属于应用、模拟器或外部服务。
- [ ] 应用全过程无新增 native crash、FATAL EXCEPTION 或 ANR；站点 429 等外部错误单独记录，不作为应用卡顿修复依据。
- [ ] 若没有新的可重复应用热点，明确以证据结论结束且不改源码；若有热点，只提交最小性能修复，UI 和非性能行为 diff 为零。
- [ ] 若有代码改动，定向测试、相关回归、analyze 和同场景前后性能复测通过，改善量可量化；若无代码改动，运行时验证与日志分析构成质量证据。
- [ ] 结束时再次校验 GitHub 原始 APK SHA-256 未变化，并确认工作区未混入用户已有改动。

## Out of Scope

- 修改或重新发布 GitHub 原始 APK。
- 修复 UI、样式、文案、功能缺失、站点 429、登录、AI、Notion、代理或 direct/full 网络功能差异。
- 为追求零慢帧而降低内容质量、隐藏内容、取消图片/评论、改变列表结构或刷新率产品语义。
- 绕过 Cloudflare、使用用户凭据抓取受保护数据或执行任何社区写操作。

## Open Questions

- 无阻塞问题；用户已经明确授权持续真实浏览、日志分析和仅限性能的最小修复。
