# Fix Reading Interactions Verification and Login Persistence

## Goal

修复帖子阅读链路中的几个交互回归，并改善第三方登录会话保持能力。目标是在不引入高风险架构改动、不存储第三方明文密码的前提下，让阅读页动画、树形楼层进度、AI 默认上下文、后台验证提示、回复展开和登录 WebView 持久化表现稳定一致。

## Requirements

- 顶部导航栏在滚动隐藏/显示时必须使用和底部栏一致的过渡参数：200ms，默认线性曲线；不能再瞬间消失。
- 树形视图底部跳转按钮的当前楼层数字必须随实际浏览位置更新，总楼层保持原逻辑。
- AI 助手左滑入口默认上下文范围从前 5 楼改为全部帖子。
- Cloudflare/访问验证自动后台流程不得再弹出频繁的前台失败提示；后台状态和日志可保留。
- 正常视图中他人回复默认展开；树形视图中已知层级默认展开，并在有子回复但尚未加载时自动加载可见节点的下一层回复。
- 保持树形视图分页机制和“加载更多”按钮，但自动加载不应破坏现有分页保护。
- 第三方登录优先通过持久化 WebView 会话、cookie、DOM storage 和非隐身 profile 保持登录状态；不得自行采集或保存第三方账号密码。
- 登录页要在用户回到第三方登录选项时尽量复用既有第三方会话，减少重复输入。

## Acceptance Criteria

- [ ] 顶栏滚动隐藏/显示有渐隐/位移动画，动画时长与底部栏一致。
- [ ] 树形视图滚动时进度控件左侧当前楼层不再固定为 1。
- [ ] 新进入 AI 助手时默认上下文为全部帖子。
- [ ] 自动访问验证失败不会触发全局 Toast/顶部通知循环。
- [ ] 正常视图有回复的帖子会自动显示回复列表。
- [ ] 树形视图不再默认显示折叠汇总条，子回复默认展开/加载。
- [ ] 第三方登录 WebView 使用持久化配置，不启用 incognito/清缓存；不新增第三方密码采集。
- [ ] Dart format、静态分析和相关测试通过，或明确记录无法执行的原因。

## Out of Scope

- 不合并上游大范围更新。
- 不新增第三方依赖。
- 不实现自建第三方密码管理器或明文/可逆密码存储。
- 不改变论坛账号原有自动填充逻辑以外的安全模型。

## Technical Notes

- 主要影响 Flutter UI、WebView 登录、CF 自动验证和 AI provider 默认值。
- 需要遵守项目现有时间处理、依赖管理和 Trellis 质量门禁。
- 安全决策：第三方凭证保持优先依赖平台 WebView 的 cookie/session/profile 持久化；原始密码只能交给系统/WebView/Provider 自己处理。
